# 노벨 실험 노트

노벨 과학상(물리학, 화학, 생리의학)의 핵심 원리를 직접 손으로 움직여 보는 인터랙티브 웹사이트입니다. 2026년에서 시작해 과거로 한 해씩 거슬러 올라갑니다.

> 노벨 재단과 관련 없는 비공식 교육용 프로젝트입니다. 노벨 재단의 로고, 메달 이미지, 수상자 사진은 쓰지 않습니다.

## 지금 상태

- 홈 화면: 소개, 연도 타임라인, 부문과 연도 필터, 연도별 카드 목록, 한국어와 영어 전환, 밝은 테마와 어두운 테마
- 체험 화면: 캔버스, 컨트롤, 관찰, 조작, 이해 탭, 미션, 재생과 초기화
- 완성된 체험: 2026 물리학(IceCube), 다섯 장으로 연구 과정을 따라감
  1. 빛의 충격파 (하위헌스 원리, 각도기로 체렌코프 각 재기)
  2. 검출기 설계 (센서 예산, 깊이별 투명도, 흡수와 산란)
  3. 잡음 속 신호 (거름 조건, 순도와 효율, 블라인드 분석)
  4. 방향과 에너지 (손 추정, 직선 맞춤, 정밀 맞춤, 트랙과 캐스케이드, 에너지 눈금)
  5. 발견 재현 (NGC 1068 하늘 지도, 새 하늘 도전, 2017년 TXS 0506+056 경보)
- 완성된 체험: 2026 화학(카강, 소아이), 네 장으로 작은 치우침이 커지는 과정을 따라감
  1. 반반의 세계 (거울상 분자 돌려 보기, 파스퇴르처럼 결정 나누기)
  2. 짝을 짓는 촉매 (리간드 짝짓기, 카강의 비선형 효과)
  3. 되먹임과 소아이의 플라스크 (자기촉매, 쌍둥이 대조군)
  4. 처음 기울인 것은 누구인가 (무작위 출발, 씨앗 실험실)
- 완성된 체험: 2026 생리의학(다이서로스, 헤게만, 나겔), 네 장으로 광유전학이 만들어진 순서를 따라감
  1. 빛을 쫓는 조류 (손전등으로 조류 이끌기, 사람 눈과 반응 속도 겨루기)
  2. 개구리 알 속의 스위치 (유전자 주입과 대조군, 빛 색에 따른 감도)
  3. 신경세포에 불을 켜다 (빛 한 번에 스파이크 하나, 깜빡임 빠르기의 한계)
  4. 살아 있는 뇌의 스위치 (세포 종류 고르기, 수염 움직이기와 깨우기, 끄는 스위치)
- 장마다 결과가 "내 연구 노트"에 쌓이고, 모든 장을 기록하면 논문 초록이 완성됩니다
- 완성된 체험: 2025 물리학(클라크, 드보레, 마르티니스), 네 장으로 회로 속 거시 양자 터널링을 따라감
  1. 벽을 지나가는 파동 (벽 두께와 높이, 전자와 양성자)
  2. 손에 쥘 수 있는 양자 (조셉슨 접합 회로, 전압이 튄 순간 100번 재기, 탈출 온도, 구리 차폐, 회로 먼저 재기)
  3. 띄엄띄엄한 에너지 (마이크로파 공명, 전류에 따른 준위 간격)
  4. 큐비트로 가는 길 (그 뒤의 이야기, 라비 진동)
- 나머지 2개 체험(2025 화학, 생리의학)은 준비 중 안내가 나옵니다
- 데이터: 2026년, 2025년 (수상 사유 원문을 nobelprize.org에서 확인한 항목만 `motivation_verified: true`로 표시)

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트
npm run build    # dist 폴더에 정적 파일 생성
```

## 주소 구조

| 주소 | 화면 |
|---|---|
| `#/` | 홈 |
| `#/?field=physics&year=2025` | 필터가 적용된 홈 |
| `#/2026/physics` | 체험 화면 |
| `#/2026/physics?ch=3` | 체험의 3장 |
| `#/about` | 프로젝트 소개 |

## 폴더 구조

```
src/
  data/2026.json, 2025.json   연도별 수상 데이터
  data.ts                     데이터 병합과 정렬
  i18n.ts                     한국어, 영어 문구 (사이트 이름도 여기)
  router.ts                   주소 해석
  previews.ts                 카드 미리보기 그림
  experiment.ts               체험 화면 (탭, 미션, 재생)
  sims/                       체험 모듈과 공통 컨트롤
  main.ts                     화면 그리기와 이벤트
  styles.css                  디자인
public/fonts/                 제목 글꼴
```

## 연도 추가하기

1. `src/data/{연도}.json`을 기존 파일과 같은 형식으로 만듭니다.
2. `src/data.ts`의 `YEAR_FILES`에 추가합니다.
3. `src/previews.ts`에 `sim` 값과 같은 이름으로 미리보기 그림을 넣습니다.

## 체험 모듈 추가하기

1. `src/sims/{sim 값}/` 폴더에 `model.ts`(계산), `content.ts`(탭별 해설), `index.ts`(화면과 컨트롤)를 만듭니다. `2026-physics-icecube`가 예시입니다.
2. `index.ts`는 `src/sims/types.ts`의 `SimModule` 형태를 기본 내보내기로 제공합니다.
3. `src/sims/registry.ts`에 한 줄 추가합니다. 체험을 열 때만 불러옵니다.

## 배포

`main` 브랜치에 올리면 GitHub Actions가 테스트와 빌드를 거쳐 GitHub Pages에 배포합니다. 저장소의 Settings, Pages에서 Source를 "GitHub Actions"로 한 번 설정해야 합니다.

## 글꼴

- 제목: 카페24 써라운드 (Cafe24, OFL). `public/fonts/`에 포함
- 본문: 그리운X국한박 고운 (그리운, 국립한글박물관). 파일을 저장소에 넣지 않고 눈누 CDN에서 불러옵니다
